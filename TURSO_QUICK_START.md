# Turso Quick Start - 5 Simple Steps

**Goal**: Get Turso running with Spider databases in 30 minutes

---

## Step 1: Install Turso CLI (2 minutes)

```bash
# Install
curl -sSfL https://get.tur.so/install.sh | bash

# Verify
turso --version
```

---

## Step 2: Login to Turso (1 minute)

```bash
# Opens browser for authentication
turso auth login

# Verify
turso auth whoami
```

---

## Step 3: Upload Databases (5-10 minutes)

```bash
# Automated upload of all 20 Spider databases
python scripts/upload_to_turso.py

# This will:
# 1. Find all .sqlite files
# 2. Create Turso databases
# 3. Upload files
# 4. Generate auth tokens
```

---

## Step 4: Configure Environment (2 minutes)

Add to your `.env` file:

```bash
# Copy tokens from .env.turso (generated by upload script)
TURSO_TOKEN=eyJhbGc...

# Optional: specify organization
TURSO_ORG=querydawg
```

---

## Step 5: Test Connection (1 minute)

```bash
# Run test suite
python scripts/test_turso_connection.py

# Should see:
# ✅ ALL TESTS PASSED
```

## Quick Reference

```bash
# List databases
turso db list

# Shell into database
turso db shell concert_singer

# Get database URL
turso db show concert_singer --url
```
